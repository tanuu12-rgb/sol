# CrisisIQ 🚨

> Every second counts. Every guest matters.

AI-powered, accessibility-first crisis response 
platform for hotels that detects emergencies, 
dispatches staff, guides guests to safety, and 
adapts automatically to every guest's disability needs.

## 🚩 Problem Statement
Rapid Crisis Response

When a hotel emergency occurs:
- Staff have no intelligent coordination tool
- Guests receive no step by step guidance
- Disabled guests are completely ignored
- Response time is slow and uncoordinated

---

## ✅ Solution
CrisisIQ automates detection, dispatch, 
multilingual alerts, and accessibility-aware 
evacuation guidance so every second counts 
and no guest is left behind.

---

## 👥 Who Uses It

| Role | What They Do |
|------|-------------|
| Guest | Press SOS, follow AI guidance |
| Staff | Receive dispatch, assist guests |
| Manager | Coordinate everything from dashboard |

---

## ⚡ Key Features

### Crisis Response
- AI powered SOS with Gemini classification
- Real time manager coordination dashboard
- Auto staff dispatch by GPS proximity
- Smart evacuation routing

### Accessibility First
- Deaf guests: silent strobe alerts + haptic
- Wheelchair guests: ramp only evacuation routes
- Visually impaired: spatial audio guidance
- Non-verbal guests: one tap pictogram SOS
- Cognitive disability: simplified 3 button UI

### Gamified Training
- Crisis scenario simulator
- Points, levels and badges
- Hotel facility rewards
- Completion certificate with QR verification

### Post Crisis
- AI generated debrief report
- Guest wellness check messages
- Incident timeline and metrics
